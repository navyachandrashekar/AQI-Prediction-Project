#  Air Quality Index Prediction System

## Project Overview
This project is a Machine Learning based web application developed to predict Air Quality Index (AQI) levels and classify health risk categories across Indian cities using environmental and meteorological data.

The system helps users analyze pollution levels, compare city-wise AQI conditions, and understand health impacts through interactive visualizations and predictive models.

---

## Features
- AQI Prediction using Machine Learning
- Health Risk Level Classification
- City-wise AQI Comparison
- Data Visualization Dashboard
- Interactive Web Application
- Pollution Trend Analysis
- User-Friendly Interface

## Dataset
The project uses Indian Air Quality datasets containing:
- PM2.5
- PM10
- NO2
- SO2
- CO
- Meteorological and environmental parameters

Dataset Source: Kaggle

- Linear Regression

## How to Run the Project
1. Download the project files
2. Install required Python libraries
3. Run the Flask application:
```bash
python app.py
```
4. Open the localhost link in your browser
